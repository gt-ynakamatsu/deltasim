# 式文法リファレンス（SV サブセット）

`deltasim` の対話デバッグ（`when`・`bp`・`examine`・`expr`）で使える式の文法です。  
Python の `eval/exec` は使わず、自前のパーサで評価します（§18.4）。

---

## リテラル

| 書き方 | 例 | 値 |
|--------|----|----|
| 10 進整数 | `42`, `255` | 整数 |
| SV 形式（サイズ付き） | `4'b1010` | 10 |
| SV 形式（16 進） | `8'hFF` | 255 |
| SV 形式（8 進） | `4'o7` | 7 |
| SV 形式（10 進） | `4'd15` | 15 |
| C スタイル 16 進 | `0xFF`, `0x1A` | 整数 |
| x / z リテラル | `x`, `z`, `4'bx01z` | None / Z_VALUE |

x または z を含む SV リテラルは x (None) を返します。

---

## 信号参照

環境（現在の信号値辞書）に含まれるシンボルを参照できます。

```
count           → count 信号の現在値（整数）
rst_n           → rst_n 信号の現在値
_cycle          → 現在のサイクル番号（test() 内の expr チェック用）
```

## 演算子（優先順位：高いほど先に評価）

| 優先順位 | 演算子 | 説明 |
|---------|--------|------|
| 12（最高） | `( )` | グループ化 |
| 11 | 単項: `~` `!` `-` `+` `&` `\|` `^` `~&` `~\|` `~^` | ビット反転・論理否定・縮約 |
| 10 | `*` `/` `%` | 乗算・除算・剰余 |
| 9 | `+` `-` | 加算・減算 |
| 8 | `<<` `>>` `<<<` `>>>` | シフト |
| 7 | `<` `>` `<=` `>=` | 比較 |
| 6 | `==` `!=` `===` `!==` | 等値（`===`/`!==` は x/z 厳密比較） |
| 5 | `&` | ビット AND |
| 4 | `^` `^~` `~^` | ビット XOR / XNOR |
| 3 | `\|` | ビット OR |
| 2 | `&&` | 論理 AND |
| 1 | `\|\|` | 論理 OR |
| 0（最低） | `? :` | 三項演算子 |

## ビット選択 / 範囲選択

```
a[2]      # ビット 2 を選択
a[7:0]    # ビット 7〜0 を範囲選択（8 ビット）
a[15:8]   # ビット 15〜8
```

---

## x / z の扱い

- x（不定）は内部的に `None` で表します。
- z（ハイインピーダンス）は内部的に `Z_VALUE` で表します。
- ほとんどの演算で x または z が含まれると結果は x（`None`）になります。
- `===` / `!==` は x/z を含む厳密比較を行います。
- `when` / `bp` の条件式で x/z が返った場合は `False` として扱います。

---

## 使用例

```tcl
# when での使用
when {count != 0} {puts "running"}
when {count == 10} {puts "done!"}
when {rst_n === 0} {puts "reset (strict)"}

# expr での使用
expr {count + 1}
expr {(count & 0xF) > 5}
expr {count[3:0]}

# ブレークポイントの条件（将来対応）
bp -cond {count > 5}
```

## エラー

構文エラーや未定義シンボルは `ExprError` として報告されます。  
不正な入力でもパーサは有限時間で終了します（再帰深さ上限: 128）。

```
ExprError: 式の不正な文字: '@' (位置 3)
ExprError: 未定義のシンボル: 'foo'
ExprError: 式の入れ子が深すぎます
```
